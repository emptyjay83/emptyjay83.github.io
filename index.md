# Email Assistant

Email Assistant is a personal tool that I run on my own computer to help manage my own Gmail inbox. It is not a public service and is not offered to anyone else.

With my permission, it signs in to my Google account to sort and label new email, archive low-priority mail and move spam to Trash, add events to a separate "Assistant" calendar that it created, and add reminders to a separate "Assistant" list in Google Tasks.
